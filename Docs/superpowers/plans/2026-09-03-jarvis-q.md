# JARVIS-Q Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CLI `ask(texto) -> AskResult` with explicit modes `regra | rede | hibrido | regra_fallback`, wrapping `notebooks/reasoning_neuron_viabilidade.py` plus TensorBoard playbook FAQ.

**Architecture:** Python-only v1. Router is deterministic (no LLM). Knowledge graph loads from versioned JSON. Playbook answers parse `public/playbook-tensorboard.html` sections `f1`–`f15`. Neural path uses `ViabilityReasoner.report()` and `TripleScorer`; hybrid wins when a toy `Rule.body` matches the asked path. TensorFlow.js, Eros/RAG, Supabase, and TTS are out of this plan.

**Tech Stack:** Python 3.11+, TensorFlow/Keras (same as notebook, `tensorflow>=2.17`), pytest, stdlib `html.parser` / regex for playbook.

**Spec:** `Docs/superpowers/specs/2026-09-03-jarvis-q-tf-design.md`

## Global Constraints

- Contract fields exactly: `resposta` (PT-BR), `modo`, `porque`, `fontes` (`list[str]`)
- One `modo` per turn; `regra_fallback` only when TF import fails **and** playbook matches
- Recusa: `modo=regra`, `fontes=[]`, `porque=sem_match`
- Playbook canonical path: `public/playbook-tensorboard.html` (not scratchpad, not PDF)
- KG fixture: `data/jarvis/kg-toy.json` copied from `_toy_demo` (not empty graph)
- Entity ids use prefixes (`bairro:savassi`), never bare `"Savassi"`
- Viabilidade: assert “viável” only if `rotulo=alta` (≥0.66); `media`/`baixa` = incerteza no texto
- `infer_threshold` default 0.7 for inferred triples
- Hybrid vs rede: hybrid wins if rule body grounds; else rede
- Do not import `@tensorflow/tfjs`; do not call Eros/LLM; do not write GitHub PAT
- Commit only if the human asks
- Windows: pytest via `.venv` Python; PowerShell one-liners (no bash `\` line continuations)

### Task 2: Playbook FAQ parse (no TF)

**Files:**
- Create: `scripts/jarvis_qa.py` (partial: types + playbook + parse helpers)
- Modify: `scripts/jarvis_qa_test.py`

**Interfaces:**
- Consumes: `public/playbook-tensorboard.html` sections with `id="f1"` … `id="f15"`; each has `<h2>Title</h2>` (file is huge because of base64 images — parse by regex, do not copy HTML into the plan)
- Produces:
  - `AskResult` TypedDict: `resposta: str`, `modo: str`, `porque: str`, `fontes: list[str]`
  - `PlaybookFaq` dataclass: `section_id: str` (e.g. `f13`), `title: str`, `snippet: str`
  - `load_playbook(path: Path) -> list[PlaybookFaq]`
  - `match_playbook(text: str, faqs: list[PlaybookFaq]) -> PlaybookFaq | None`
  - `parse_intent(text: str, entity_names: list[str]) -> tuple[str, list[str]]`  
    intent ∈ `playbook_aba | viabilidade | relacao_kg | lixo`  
    entities = matched `entity2id` keys (prefix ids)

**Intent rules (fixed strings, casefold, NFKC):**

- If text contains `viavel` or `viável` or `viabilidade` **and** at least one entity match → `viabilidade`
- Else if text contains `herda_renda` or `bairro_bh_herda_renda` or (`herda` and `renda`) → still parse entities; hybrid is decided later in `ask()`, not here. Intent stays `viabilidade` if viabilidade words present, else if two entity ids and a relation name from `relation2id` → `relacao_kg`
- Else if `match_playbook` hits → `playbook_aba`
- Else → `lixo`

**Entity match:** for each key in `entity2id`, if the part after `:` (or full key) appears as substring in casefolded text, collect that key. Example: `"savassi"` → `bairro:savassi`.

**Playbook match:** casefold query; if `"projector"` in query or title casefold equals/contains query tokens, return the FAQ whose `title` is `Projector` (`f13`). Generic: first FAQ whose title (casefold) is a substring of the query or vice versa (min title length 4 to avoid `PCA` false friends if needed — `Projector` is 9 chars). Unknown aba: `match_playbook` returns `None`; `ask()` later lists titles 01–15.

**Snippet:** first `.eli5` `<p>` text inside the section if present; else first 400 chars of stripped tags in the section. `resposta` for regra = snippet + title, PT-BR.

```python
from __future__ import annotations

import json
import re
import sys
from dataclasses import dataclass
from pathlib import Path
from typing import TypedDict

ROOT = Path(__file__).resolve().parents[1]


class AskResult(TypedDict):
    resposta: str
    modo: str
    porque: str
    fontes: list[str]


@dataclass
class PlaybookFaq:
    section_id: str
    title: str
    snippet: str


def load_playbook(path: Path) -> list[PlaybookFaq]:
    html = path.read_text(encoding="utf-8")
    faqs: list[PlaybookFaq] = []
    for m in re.finditer(
        r'<section[^>]*id="(f\d+)"[^>]*>(.*?)</section>',
        html,
        flags=re.I | re.S,
    ):
        sid, body = m.group(1), m.group(2)
        tm = re.search(r"<h2>(.*?)</h2>", body, flags=re.I | re.S)
        if not tm:
            continue
        title = re.sub(r"<[^>]+>", "", tm.group(1)).strip()
        em = re.search(r'class="eli5"[^>]*>.*?<p>(.*?)</p>', body, flags=re.I | re.S)
        if em:
            snippet = re.sub(r"<[^>]+>", "", em.group(1)).strip()
        else:
            snippet = re.sub(r"<[^>]+>", " ", body)
            snippet = re.sub(r"\s+", " ", snippet).strip()[:400]
        faqs.append(PlaybookFaq(sid, title, snippet))
    return faqs


def match_playbook(text: str, faqs: list[PlaybookFaq]) -> PlaybookFaq | None:
    q = text.casefold()
    for faq in faqs:
        t = faq.title.casefold()
        if t and (t in q or q in t or t.split()[0] in q):
            return faq
    return None


def parse_intent(text: str, entity_names: list[str]) -> tuple[str, list[str]]:
    q = text.casefold()
    ents = []
    for name in entity_names:
        tail = name.split(":", 1)[-1].casefold()
        if name.casefold() in q or (tail and tail in q):
            ents.append(name)
    viab = any(k in q for k in ("viavel", "viável", "viabilidade"))
    if "viável" in text.casefold() or "viavel" in q or "viabilidade" in q:
        viab = True
    if viab and ents:
        return "viabilidade", ents
    rel_words = ("pertence_a", "tem_renda", "tem_aluguel", "coberto_por", "localizado_em")
    if ents and any(w in q for w in rel_words):
        return "relacao_kg", ents
    return "lixo", ents
```

**Files:**
- Modify: `scripts/jarvis_qa.py`

- Consumes: `load_kg_toy`, `AskResult`, playbook helpers; notebook classes via sys.path
- Produces:
  - `def tf_available() -> bool`
  - `def load_kg_toy(path: Path)` → `(entity2id, relation2id, triples, rules_raw)`
  - `def build_reasoner(toy: dict)` → `ViabilityReasoner` (import inside function)
  - `def ask(texto: str, *, tf_ok: bool | None = None, reasoner=None, faqs=None, toy=None) -> AskResult`

**Router (copy spec; implement exactly):**

`tf_ok` default = `tf_available()` unless tests pass `tf_ok=False`.

1. `intent, ents = parse_intent(...)`; `faq = match_playbook(...)`; if intent `lixo` and faq: intent = `playbook_aba`
2. If `not tf_ok`:
   - if intent == `playbook_aba` and faq: return `modo=regra_fallback`, `fontes=[f"playbook:#{faq.section_id}"]`, `porque=tf indisponivel; FAQ playbook`, `resposta=faq.snippet`
   - else: return recusa `modo=regra`, `fontes=[]`, `porque=sem_match`, `resposta` PT-BR explaining no TF / no match
3. If `tf_ok` and intent == `playbook_aba` and faq: `modo=regra`, `fontes=[f"playbook:#{faq.section_id}"]`, `porque=FAQ deterministica playbook`
4. Hybrid: if any toy rule `name` in query casefold **or** (`herda` in query and `renda` in query and ents):
   - `modo=hibrido`, `fontes` include `rule:bairro_bh_herda_renda` and `kg:triple`
   - `resposta` states rule name; if reasoner available, mention `regras_ativadas` / conflict: if you compute body vs head ReLU on the toy grounding `(a=savassi, mid=bh, b=renda:alta)` and body>head, append `conflito` to `porque`
   - Skip step 5 when hybrid fires
5. If ents:
   - `viabilidade` → `report = reasoner.report(ents[0])`; `modo=rede`; `fontes` include `report`; `porque` must include `rotulo={report['rotulo']}`; text: if `rotulo==alta` say viável; else incerteza, do not say viável
   - `relacao_kg` → pick first two ents or ent + object from query; score `TripleScorer.prob`; if not `is_known` and prob < 0.7: incerteza, do not assert fact; `modo=rede`; `fontes` include `kg:triple`
6. Recusa `sem_match`

**Unknown entity:** query looks like viabilidade but no ents → recusa + `resposta` lists example `bairro:savassi`.

**Unknown aba:** query mentions `aba` / `tensorboard` / numbered tab not in titles → `resposta` lists the 15 `PlaybookFaq.title` values; `porque=sem_match` or a dedicated phrase; `modo=regra`; `fontes=[]`.

def build_reasoner(toy: dict):
    rn = _import_neuron()
    kg = rn.KnowledgeGraph(toy["entity2id"], toy["relation2id"], [tuple(t) for t in toy["triples"]])
    rules = [rn.Rule(body=r["body"], head=r["head"], name=r["name"]) for r in toy["rules"]]
    return rn.ViabilityReasoner(kg, embedding_dim=32, max_hops=2, rules=rules)
